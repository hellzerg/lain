# Changelog

## [4.0] — 2026-11-24
- New: Major visual overhaul
- New: Introduced AES-256-GCM encryption and HMAC-SHA-256 integrity protection.
- New: Versioned cryptographic identifiers, bounded KDF parameters, and Windows CNG support 
- New: Enforce password strength during creation, changes, and relevant security-mode changes.
- New: HaveIBeenPwned integration and better security report
- New: FIDO2 / WebAuthn support with ES256/P-256 with required user verification.
